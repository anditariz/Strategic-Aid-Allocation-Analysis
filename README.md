# Strategic Aid Allocation Analysis 🌍

## Project Overview
This project aims to help humanitarian organizations prioritize international aid. By using data-driven methods, I identified "Red Zone" countries that need urgent assistance based on health, economic, and demographic factors.

## Key Features
- **Data Clustering:** Used K-Means algorithm to group 167 countries into priority levels.
- **Interactive Dashboard:** Built with Power BI to visualize global aid needs.
- **Actionable Insights:** Provides a clear roadmap for strategic resource allocation.

## Tools Used
- **Analysis:** Python (K-Means Clustering)
- **Visualization:** Power BI
- **Documentation:** Microsoft Word / PDF

## How to Use
1. Open the `.pbix` file to interact with the dashboard.
2. Read the `Proyek Akhir.pdf` for a detailed explanation of the methodology and results.

## Conclusion
Data is more than just numbers; it's a tool for empathy. This project proves that quantitative analysis can help ensure that no one is left behind in global humanitarian efforts.
